# Bioinformatics Analysis Toolkit Demo

Educational Python toolkit for DNA and protein sequence analysis, including ORF detection, DNA-to-protein translation, GC-content profiling, protein feature estimation, hydropathy analysis, and sequence-logo visualization.

## Overview

This repository contains educational and portfolio-oriented bioinformatics analysis tools developed in Python. The repository is organized as a collection of small analysis modules, each focusing on a specific area of computational biology or biological data analysis.

The first module currently included is a DNA and protein sequence analysis toolkit. It demonstrates basic workflows such as ORF detection, DNA-to-protein translation, GC-content profiling, protein physicochemical feature estimation, hydropathy analysis, and sequence-logo visualization.
